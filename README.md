# Pope

Sistema de gestión para cibercafés, inspirado en SENET:

- Cada PC arranca directamente en un **Shell bloqueado**; el cliente inicia sesión con una cuenta creada en el **nodo central** del local.
- El tiempo de uso se descuenta del saldo; el cliente puede **pausar** su sesión sin que se le cobre.
- El local vende productos con **inventario al día** y cierre de caja por turno.
- El dueño consulta el estado del local **desde una web**, esté donde esté.
